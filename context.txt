[ARCHITECTURE / CONVENTIONS]
- Per module layer: models -> repositories (tenant+entity scoped always) -> validators
  (strict unknown-field reject; create errors=INVALID_INPUT, update=VALIDATION_ERROR) ->
  services (business rules, HttpError) -> controllers -> routes. Guard chain on every
  route: requireAuth -> requireValidSubscription -> requireModule -> requirePermission.
  error.middleware: CastError->400, 11000->409 DUPLICATE_KEY, HttpError->code, else 500.
- Multi-tenant: ALL queries scoped {tenantId, entityId}; foreign access -> 404 (not 403).
- NO physical DELETE on accounting entities; state via status transitions. Update=PATCH,
  actions=POST sub-routes (/post, /close, /lock, /reopen, /current).
- Error shape: { error: { code, message, field? } }.
- Money = integer MINOR units (cents), whole safe integers, sums validated server-side.
- Accounting route mount: backend/modules/accounting/routes/index.js mounts at /api;
  entity/account/fiscalPeriod/journalEntry routes are /api/entities/:entityId/<resource>.
